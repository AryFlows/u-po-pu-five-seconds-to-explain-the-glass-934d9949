# Frost Glass Defence

The one sentence a house cat would say in its own defence, five seconds after knocking a glass off the table. No apology, no confession — just the most convincing case a cat can make for itself.

> It was already leaning, so I gave it the little push it was clearly begging for — gravity did the paperwork and I merely supervised the landing.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## Verify

```sh
MAKEFUN_OUTPUT_DIR=/tmp/glass-out python3 main.py && cat /tmp/glass-out/entry.txt
```

The line is one sentence, 144 characters, inside the 1–200 gate.
